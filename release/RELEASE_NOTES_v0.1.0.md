# GMT v0.1.0 — First research snapshot

**Attribution:** Mrityunjay K  
**Date:** 13 October 2026  
**Status:** Proposed mathematical model; not peer reviewed; not validated as a physical law.

## Contents
- GMT formulation and assumptions.
- Proofs for memory invariance, conductance bounds, weighted-mass conservation, Lyapunov dissipation, exponential consensus on connected graphs, the maximum principle, global well-posedness, memory relaxation, and edge-orientation invariance.
- Python ODE solver, graph utilities, 17 automated tests, and reproducible numerical experiments.
- Topology and memory-time sweeps, 50 seeded stress trials, and graph/energy plots.
- Generated PDF proof-and-simulation report.

## Scientific scope
This release does not claim complete worldwide novelty, legal exclusivity, or empirical validity. Adaptive diffusion and nonlinear graph-consensus systems are relevant prior art. See `docs/NOVELTY_AND_SCOPE.md`.
